v0.1.0 — Milestone 0: Boot Manager

Milestone 0 is complete: the system boots on x86_64 with UEFI, x86_64 with
BIOS, and AArch64 with UEFI, shows a boot menu, reports what it found, and
hands control to a kernel. AArch64 with BIOS is refused.

- Stage 1, Boot Pipeline Foundation: UEFI and BIOS providers, discovery and
  checking of the hardware, the memory map, and the framebuffer, the ELF64
  kernel loader, the first page tables, the kernel stack, the processor entry
  state, and the pre-transition hook for the boot menu
- Stage 2, Platform Initialization: processor, physical memory ownership,
  paging, stack, early heap, and the ELF check, with an entry stub for each
  processor family
- Stage 3, Boot Diagnostics & Recovery: a fixed-size boot log, boot status,
  error classification, the panic screen, the recovery decision, and the
  Boot Report
- Stage 4, Boot manager & UI: the boot configuration (five fields), the boot
  menu, the system summary, the decision rules, the recovery request,
  freezing the configuration, and the start of `kernel_main`
- Tests: 43 unit tests (gcc and clang), 19 QEMU tests on the three platforms
  (normal run, recovery, panic, and the menu with real key presses), 2 KVM
  tests; the manual check of the whole milestone under KVM in virt-manager
  (`docs/milestones/milestone0/manual_check.md`)
- Tools: `scripts/run_qemu.sh`, `make_image.sh`, `make_manual_images.sh`,
  `gen_font.py`; GitHub Actions CI with gcc and clang

Found during the final check and fixed: the menu hook ran after the
interrupts were masked, so the AArch64 firmware keyboard did not work; the
BIOS keyboard map had no space and no punctuation; the AArch64 jump hung on
a processor with LPA2 (the libvirt default `-cpu max`) because it wrote
`TCR_EL1` while the firmware MMU was on; the menu left its text on the screen
under the recovery screen.

Not included: a run on a physical machine (the manual check was done under
KVM), saving the configuration between boots, choosing a kernel, an
interactive recovery, platform reset and power-off, upper-case letters on the
BIOS keyboard.
